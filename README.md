# AndroidApp3 – City Treasure Hunt

## About the App

City Treasure Hunt is an Android application created for my Android development assignment.

The app allows participants to complete a Treasure Hunt by visiting 20 locations around Brampton, Ontario. The hunt begins at Brampton City Hall and guides the participant through the remaining locations.

After visiting all 20 locations, the participant becomes eligible for a draw for a free vacation.

## Features

- 20 Treasure Hunt locations around Brampton
- Starts at Brampton City Hall
- Uses the device's current GPS location
- Calculates the distance to the current Treasure Hunt location
- Marks a location complete when the participant is within 100 metres
- Updates the participant's progress from 0/20 to 20/20
- Reveals the next location after completing the current location
- Saves Treasure Hunt progress
- Displays a completion message after all 20 locations are visited

## Technologies Used

- Android Studio
- Kotlin
- Android Location API
- Google Play Services Location
- Fused Location Provider
- SharedPreferences
- Git and GitHub

## Testing

The application was tested using the Android Emulator. The emulator's location controls were used to simulate different locations around Brampton and verify the distance calculations and Treasure Hunt progression.
