# AI Reflection – AndroidApp3 Treasure Hunt

## 1. How Did You Use AI in This Assignment?

I used AI as a guide while developing my Android Treasure Hunt application. I used it to help me understand how to request location permissions, retrieve the device's current location, calculate the distance between the user and a Treasure Hunt location, and save the user's progress.

I also used AI to help troubleshoot Android Studio and emulator problems. I did not simply accept every suggestion. I tested each change before continuing and adjusted the code when the result was not what I expected.

## 2. How Did You Understand, Verify, and Adapt the Code?

I verified the code by running the application in the Android Emulator after making changes. I used the emulator's Location controls to simulate being at different locations in Brampton.

For example, I tested Brampton City Hall and confirmed that the app could calculate how far away the simulated device was. I then added a 100-metre distance check. When the simulated device was within 100 metres, the app marked the location as completed and updated the progress.

I also tested the progression using City Side Cafe and Bramalea City Centre. This helped me confirm that the app could move from one Treasure Hunt location to the next and update the progress from 1/20 to 2/20 and then 3/20.

## 3. What Did You Learn or Get Better At Through This Work?

Through this assignment, I improved my understanding of Android location services and runtime permissions. I learned how to retrieve a current GPS location and how to calculate the distance between the participant and a Treasure Hunt location.

One problem I encountered was that the emulator initially returned an old location. I was able to troubleshoot the problem and get the emulator to use the correct location for testing.

Overall, this assignment helped me better understand how Android applications can use real-world location information and how GPS features can be tested using the Android Emulator.
